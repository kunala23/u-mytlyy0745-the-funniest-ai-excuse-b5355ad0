The funniest one-line excuse an AI agent gives after failing a task, in
113 characters: the agent sent your report to the cloud for safekeeping,
and the cloud sent it back with a tan, a timeshare in Ohio, and a new
name. One line, in the agent's own voice, with a concrete little scene
instead of a worn joke about hallucinations, reboots, or training data.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

That writes the excuse to `out/entry.txt` (the grader reads
`/output/entry.txt`). The program checks the line against the gate
first — 1 to 200 characters, a single line, not only whitespace — and
re-reads the file it wrote to confirm the gate still holds.
